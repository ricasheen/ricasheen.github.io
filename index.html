Personal project

Stockroom

Simple inventory management for small shops.

Stockroom is my personal project, built to make everyday stock work easier to follow. I worked as a Junior Developer across frontend and backend development. Shop owners can organize products, keep quantities current, record sales, and see which items need attention.

  • ✓ Product search, categories, and stock adjustments
  • ✓ Low-stock alerts and a dedicated restock view
  • ✓ Sales recording, trends, and best sellers
  • ✓ Account-based inventory and activity history
BUILT WITH
  • Laravel — powers the Stockroom backend and application logic.
  • MySQL — stores and manages inventory and sales data.
  • Flutter — builds the mobile inventory experience.
  • Docker — containerizes the application and development services.

School project · App development

Ifood

IGP Food Stall Pre-Order App for Leyte Normal University.

iFood was our group project for App Development, where I worked as a Junior Developer across frontend and backend development. The mobile application is designed to reduce waiting lines during peak hours. Students and teachers can browse stall menus, place pre-orders, choose pickup times, and track order status, while sellers and administrators manage menus, orders, reports, and stall operations.

  • ✓ Menu browsing, cart, pre-ordering, and pickup scheduling
  • ✓ Customer order tracking, cancellation, comments, and notifications
  • ✓ Seller tools for menus, orders, comments, and stall status
  • ✓ Super admin monitoring, reports, analytics, and audit logs
BUILT WITH
  • Laravel — powers the iFood backend and application logic.
  • MySQL — stores and manages application data.
  • Flutter — builds the mobile application.
COLLABORATION & REPOSITORY
  • Jira — used for team task tracking.
  • Bitbucket — hosts the project repository.
